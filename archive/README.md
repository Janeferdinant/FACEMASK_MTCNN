# archive: legacy site files, not part of this project

The files in this folder have nothing to do with face-mask detection. They look like leftovers from an earlier website that was published from this repository, and were moved here from the repository root so the root only holds the project. They were moved (with `git mv`), not deleted, and their history is preserved.

| File | What it is |
|---|---|
| `AI tools.html` | A static page of links to third-party AI and marketing tools. |
| `stylesheet.css` | Style sheet that appears to belong to the same old site (nothing in this repository references it any more). |
| `*.jpeg` (18 images) | Thumbnails named after unrelated projects (for example "Loan Prediction", "Movie Recommender System", "Sales Performance Dashboard with Power BI") and a few generic pictures (`future`, `gan`, `pink`, `trend`). |

Nothing in the notebooks, the demo or the project page uses these files. They are kept here only so the owner can decide what to do with them; any file that is no longer wanted can be removed in a later, separately approved change.

The project itself is described in the [main README](../README.md).
